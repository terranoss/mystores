MyStore Installation Guide

Welcome to MyStore! This guide walks you through setting up both your self-hosted **Web Management Dashboard** and the **Flutter Companion Mobile App**.

What's in your download zip package:

When you extract mystores-v1.0.0.zip, you will find:

Folder / File Description
Web_and_Backend/ (or web/) Pre-compiled Laravel 12 backend + React 19 frontend assets. Upload this directly to your hosting / cPanel.
Documentation/ Offline installation and user documentation guide.
README.txt Quick orientation file with 5-minute setup instructions and Google Play App link.

Server Requirements

Ensure your shared hosting (cPanel), VPS, or cloud server meets these requirements:

  • PHP: Version 8.2 or newer
  • Database: MySQL 5.7+ or MariaDB 10.3+ (or SQLite)
  • Required PHP Extensions: pdo_mysql, openssl, mbstring, curl, gd, zip, fileinfo, dom
  • Web Server: Apache (with mod_rewrite enabled) or Nginx
💡
Note for cPanel Users: You do NOT need Node.js or Composer installed on your cPanel. The web/ folder is completely pre-built and ready to run.

1. Database Creation (cPanel)

Before launching the web installer, create an empty MySQL database in your hosting control panel:

  1. Log into your cPanel.
  2. Navigate to MySQL Databases (or MySQL Database Wizard).
  3. Create a new database (e.g., username_mystore).
  4. Create a database user with a secure password.
  5. Add the user to the database and check ALL PRIVILEGES.

2. Uploading Files to Hosting

  1. Open cPanel File Manager.
  2. Go to your domain document root (usually public_html or your subdomain directory).
  3. Upload all files inside the web/ directory of your downloaded package.
  4. Ensure the storage/ and bootstrap/cache/ folders have write permissions (Permission 755 or 775).

3. The Web Setup Wizard

Open your browser and navigate to your website:

https://your-domain.com/install

MyStore automatically presents a 5-step interactive setup wizard:

  • 1 Preflight Check: Automatically validates your PHP version, extensions, and directory write permissions with instant green badges.
  • 2 License Activation: Enter your License Key purchased from Stacklane (e.g. MSTR-XXXX-XXXX-XXXX). It activates seamlessly via HTTPS.
  • 3 Database Connection: Enter your DB Host (usually 127.0.0.1), Database Name, User, and Password. Click "Test Connection" to verify before proceeding.
  • 4 Admin & Store Setup: Personalize your Store Name and choose your primary Superadmin Name, Email, and Password.
  • 5 Initialization & Lockout: MyStore runs migrations, seeds initial data, saves your license certificate, and permanently locks the /install routes.

How Staff & Cashiers Connect (Zero-Configuration)

Your team members never have to configure server URLs or edit code:

  1. Admin Creates Member: In your web dashboard, navigate to Team > Add Team Member. Enter the staff member's Name, Email, and Password.
  2. Staff Installs App: Have the staff download MyStores from the Google Play Store.
  3. Scan Store QR: On opening the app, staff taps "Scan Store QR Code" and scans the Store QR displayed on your admin Team page. (Or they can type your store domain: https://your-domain.com).
  4. Sign In: The app connects to your server instantly. Staff enters their email and password to access their orders, pick lists, and inventory!
📱
Multi-Store Staff Support: If a team member works across multiple stores or branches, they can simply tap "Change" on the sign-in screen or select "Switch Store" in the app navigation drawer to connect to another server anytime.

Marketplace Integration Guides

Connect your Shopee and Lazada seller accounts from your web dashboard:

Shopee Open Platform:

Go to Settings > Integrations > Shopee. Enter your Partner ID and Partner Key. Set your authorized redirect URL in Shopee Open Console to: 

https://your-domain.com/api/shopee/callback

Lazada Open Platform:

Go to Settings > Integrations > Lazada. Enter your App Key and App Secret. Set your authorized callback in Lazada Open Platform to: 

https://your-domain.com/api/lazada/callback

Common FAQs & Troubleshooting

500 Internal Server Error after uploading

Ensure file permissions are correct. On cPanel, directories must be 755 and files 644. Verify that storage/ and bootstrap/cache/ are writable by PHP.

Removing /public from URL

If your URLs require /public/, make sure Apache's mod_rewrite is enabled and your domain document root points directly to the web root folder.

How do I re-run the installer?

For security, the installer is permanently disabled once completed. If you need to reinstall from scratch, delete the storage/installed file and .env file.
